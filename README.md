# Nike Demo Website
วิธีรันเว็บ
#### วิธีที่ 1: ใช้ Live Server (แนะนำ)
1. เปิดโฟลเดอร์ `site` ใน VS Code
2. คลิกขวาที่ `index.html` แล้วเลือก "Open with Live Server"
3. หน้าเว็บจะเปิดใน browser อัตโนมัติ

#### วิธีที่ 2: ใช้ Python HTTP Server
1. เปิด PowerShell หรือ Command Prompt ในโฟลเดอร์ `site`
2. รันคำสั่ง:
   ```powershell
   python -m http.server
   ```
3. เปิด browser ไปที่ `http://localhost:8000`

### 4. การแก้ไขและพัฒนา
- แก้ไขไฟล์ HTML/CSS/JS ในโฟลเดอร์ `site`
- ทุกการเปลี่ยนแปลงต้องบันทึกไฟล์ก่อนรีเฟรชหน้าเว็บ
- ถ้า Live Server หรือ Python server ไม่แสดงผลใหม่ ให้ปิดแล้วเปิดใหม่

### 5. ปัญหาที่พบบ่อย
- ถ้าแก้ไขแล้วหน้าเว็บไม่เปลี่ยน: กด Ctrl+F5 เพื่อรีเฟรชแบบไม่ใช้ cache
- ตรวจสอบว่า server เปิดอยู่ในโฟลเดอร์ `site` จริง
- ตรวจสอบว่าไฟล์ที่แก้ไขถูกบันทึกแล้ว
